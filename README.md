# Guess Word Game · 猜单词游戏

一个用 C++ 手写的猜单词(Hangman)游戏,基于 4452 个大学英语四级词汇,词库与中文释义以数组形式直接写死在源码里。

作者入坑信息学竞赛(OI)半个学期(高一,约 2022 年 12 月)时独立完成,是 OI 早期的原始小作品,保留至今。

## 玩法

- 程序从内置的 4452 个 CET-4 单词中随机抽取一个作为目标词
- 按单词字母数显示下划线,逐字母猜测
- 猜对则填入对应位置;猜错则错误计数 +1,超过设定的上限即失败
- 猜完所有字母即胜利,每局结束显示该单词的中文释义
- 输入 `1` 可继续下一局

## 文件说明

## 构建运行

源码为 GBK 编码、Windows 控制台程序,使用支持 GBK 的编译器编译:

```bash
g++ 猜单词.cpp -o 猜单词.exe
./猜单词.exe
```

已附带的 `猜单词.exe` 可直接运行。

## 说明

- 词库取自大学英语四级词汇,中文释义由程序在每局结束后展示
- 源码注释与输出为 GBK 编码,在 UTF-8 终端下可能显示乱码,这是当年的时代特征,原样保留
- 原版使用 `system("cls")` 清屏、`random_shuffle` 抽词等朴素实现,作为早期 OI 学习的原始记录不做改动
- `AI代码精修/` 为后续重构版本,展示了代码组织的改进(数据与逻辑分离)
